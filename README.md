# Simple Calculator

## Description
A Simple Interest Calculator calculates the interest on a principal amount based on a fixed annual interest rate and time period.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Annual Interest Rate
- T = Time in Years

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100
Simple Interest = 100

Total Amount = 1000 + 100 = 1100

## Features
- Calculates simple interest.
- Calculates total amount.
- Easy to understand.
